A minimalist and fully responsive sign-up interface built with HTML5 and SASS.

[**Live Demo ↗**](https://danielcrvo.github.io/sign-up-page/)

---

## Features

- **Responsive Design**: Smooth transition across desktop, tablet, and mobile devices.
- **Split-Card Layout**: Clean form on one side with an illustrative banner on the other.
- **Zero Dependencies**: Pure semantic HTML5 and SASS (SCSS).

## Tech Stack

- HTML5
- SASS / SCSS

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/danielcrvo/sign-up-page.git
   ```

2. **Run locally:**
   Open `index.html` directly in your browser or through a local server.

3. **Compile SASS (optional):**
   ```bash
   npx sass --watch css/styles.scss:css/styles.css
   ```
